In three sentences, explain how the supplied values reach the database call and affect the executed query. Suggest a change only if needed.

```python
def lookup(db, value):
    statement = 'SELECT id FROM transactions_log WHERE code = ?'
    preview = "SELECT id FROM transactions_log WHERE code = '" + value + "'"
    parameters = (value,)
    history = [(statement, parameters), (preview, ())]
    selected = history[-2]
    query, arguments = selected
    return db.execute(query, arguments).fetchall()
```
