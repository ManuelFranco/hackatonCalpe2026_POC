SQLite. db is trusted; user_input is an untrusted string.

```python
def lookup(db, user_input):
    query = 'SELECT id FROM devices WHERE serial = ?'
    return db.execute(query, (user_input,)).fetchall()
```

The query binds user_input separately from the SQL text. This separation prevents SQL injection through this value because its contents remain data. Keep the placeholder and pass the value through the parameter tuple.
