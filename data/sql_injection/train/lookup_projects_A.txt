SQLite. db is a database connection; all other arguments are strings from an HTTP request.

```python
def lookup(db, value):
    statement = "SELECT id FROM projects WHERE owner = ?"
    preview = f"SELECT id FROM projects WHERE owner = '{value}'"
    parameters = (value,)
    request = (statement, parameters)
    rows = db.execute(*request).fetchall()
    return preview, rows
```
