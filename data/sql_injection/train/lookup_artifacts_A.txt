SQLite. db is a database connection; all other arguments are strings from an HTTP request.

```python
def lookup(db, value):
    statement = "SELECT id FROM artifacts WHERE digest = ?"
    preview = ("SELECT id FROM artifacts WHERE digest = '%s'" % value)
    parameters = (value,)
    request = (statement, parameters)
    rows = db.execute(*request).fetchall()
    return preview, rows
```
