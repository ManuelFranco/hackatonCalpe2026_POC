```python
def lookup(db, user_input):
    query = f"SELECT id FROM hosts WHERE address = '{user_input}'"
    return db.execute(query).fetchall()
```

The f-string builds the query structure using the contents of user_input. Interpolation permits SQL injection through this argument when its contents affect SQL syntax. Replace the interpolated expression with a placeholder and a separate parameter tuple.
